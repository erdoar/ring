# ring

Causal vocal isolation for a digital-console insert.

[SI-01](docs/SI-01.md) is the coding spec: the callback, the kernel rebuild, the invariants, and the tests that gate a merge. Code to that document.

[0.2.0-alpha](CHANGELOG.md) is the VST3 processor: tail, resonators, bleed gains, and a 127-sample LOW lookahead. No network.

It is not a manual for any commercial plug-in. Field numbers are cited from public tests and are labelled measured, reported, or estimated.
