Ring

Real-time vocal isolation and feedback detection for a digital-console insert. A macOS app for Apple Silicon that takes up to eight channels from your console's USB interface.

Download for macOS Source on GitHub

Prototype. Free and open source. Apple Silicon Mac required.

What it does

Room tail removal

Learns the room's reverb from the mic and subtracts it, capped so the output never drops more than a set amount below the dry signal.

Howl detection

Tracks up to eight rising, steady tones and notches them. Sung notes and vibrato stay at unity.

Voice-aware

Freezes learning while someone is singing or speaking, so the voice itself is never learned as room.

Zero or low latency

ZERO mode adds no delay. LOW mode reports 127 samples and uses them as lookahead.

Built for the callback deadline

8

channels per Mac at 48 kHz

52 µs

worst-case processing for all eight channels in a 32-sample block, against a 667 µs deadline (Apple Silicon test build)

Off-thread

Spectral analysis runs on a worker. The audio callback only filters and subtracts.

Install

  1. Download the latest .dmg from the releases page.
  2. Drag Ring into Applications and open it.
  3. The first time, open System Settings › Privacy & Security and click Open Anyway.

Ring is a prototype, not yet a validated live insert. Device routing and real-room feedback performance are still being tested. See the audit for open issues.
