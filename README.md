# ring

Causal vocal isolation for a digital-console insert.

The first document is [SI-01](docs/SI-01.md): a technical paper on reverse-impulse-response vocal isolation, written for ultra-low-latency USB and card inserts. It decides the algorithm, the latency budget, and whether the product is a plugin or a host.

It is a research note, not a manual for any commercial plug-in. Field numbers are cited from public tests and are labelled measured, reported, or estimated.
